# CLAUDE.md

The instructions for this repository live in **[AGENTS.md](AGENTS.md)**. Read it
before touching anything, and follow it in full.

They are kept in one file so that every agent works to the same rules; this file
exists only to point there.

The one that matters most, repeated here so it cannot be missed:

> **Never read, list, execute or modify anything outside this repository root.**
> Not `~`, not `/usr`, not `~/.config`, not `~/.local` — and not a `--version` on
> a binary that lives outside. The ban is lifted only by the maintainer's explicit
> authorisation, granted **per command**, after they have read the exact command.
